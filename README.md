# Portfólio — Lucas Hernandes

Landing page estática (HTML + CSS, sem dependências de build).

## Publicar no GitHub Pages
1. Crie um repositório (ex.: `lucas-hernandes.github.io` para ter o endereço raiz, ou qualquer nome).
2. Envie `index.html` e a pasta `assets/` para a raiz do repositório.
3. Em **Settings › Pages**, escolha **Deploy from a branch**, branch `main`, pasta `/ (root)`.
4. Em alguns minutos o site fica em `https://<seu-usuario>.github.io/<repositório>/`.

Para trocar textos, edite `index.html`. As imagens ficam em `assets/`.
